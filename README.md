# Praxis para computador

Instaladores do [Praxis](https://usepraxis.online) para Windows, macOS e Linux.

**Baixe pela home:** [usepraxis.online/#baixar](https://usepraxis.online/#baixar) — ela detecta o seu sistema e sugere a versão certa.

| Sistema | Arquivo |
|---|---|
| Windows 10 e 11 | `Praxis-windows.exe` |
| macOS (Apple Silicon — M1 ou mais novo) | `Praxis-mac-arm64.dmg` |
| macOS (Intel) | `Praxis-mac-x64.dmg` |
| Linux (Ubuntu, Mint, Debian e derivados) | `Praxis-linux.deb` |
| Linux (outras distribuições) | `Praxis-linux.AppImage` |

Todas as versões estão em [Releases](https://github.com/YagoLagrottiBracco/praxis-desktop/releases). Este repositório guarda só os instaladores, gerados automaticamente; o código do Praxis é privado.
